Description:
Shinsoku is a fast voice input companion for people who write across many apps.

Record speech, turn it into clean text, and reuse it from the Shinsoku keyboard wherever you type. Custom profiles let you decide how the transcript should be handled: clean dictation, conversational messages, review-first drafts, or translation such as Chinese speech to English text.

Key features:
- Realtime voice transcription with cloud speech providers
- Custom post-processing profiles for cleanup, rewriting, and translation
- iOS keyboard extension for inserting the latest Shinsoku text into other apps
- Draft history with one-tap copy
- Configurable ASR mode and post-processing model
- Clear feedback when text is copied or a profile changes settings

Shinsoku is designed for writers, builders, and multilingual users who want voice input that adapts to the task instead of forcing every transcript into the same format.

## App Review Notes

Shinsoku records user speech only after microphone permission is granted. Transcription and optional post-processing are sent to the provider configured by the user. The app includes an iOS keyboard extension that reads the latest copied Shinsoku text and inserts it into the current text field when the user taps the insert button.

Test account:
Not required.

Configuration for review:
If needed, provide reviewer-visible API settings or a test configuration before submission. The current app supports user-provided Bailian or Soniox credentials in Settings.
