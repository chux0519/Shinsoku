# Shinsoku Privacy Policy Draft

Last updated: June 24, 2026

Shinsoku is a voice input utility that turns speech into text and helps you insert that text into other apps.

## Information You Provide

Shinsoku may process:
- Audio you record in the app.
- Transcript text generated from that audio.
- Draft text stored inside the app during the current session.
- Provider configuration you enter, such as API endpoints, model names, and API keys.

API keys and provider settings are stored locally on your device using secure storage.

## How Processing Works

When you start transcription, Shinsoku sends the recorded audio to the speech provider you configure in Settings. If text post-processing is enabled, Shinsoku sends the transcript and selected profile prompt to the configured text model provider.

Shinsoku does not operate its own analytics, advertising, or tracking service in the app.

## Keyboard Extension and Clipboard

Shinsoku includes an iOS keyboard extension. The app writes the latest transcript to the system clipboard so the keyboard extension can insert it when you choose to paste or insert Shinsoku text.

## Third-Party Providers

Your selected speech or text provider may process audio, transcript text, prompts, API keys, IP addresses, and related request metadata according to that provider's own terms and privacy policy. Review your provider's policies before using cloud transcription or post-processing.

## Data Retention

Shinsoku stores provider settings locally on your device. Draft history shown in the app is kept locally during app use. Cloud providers may retain request data according to their own policies.

## Tracking and Advertising

Shinsoku does not use data for tracking, advertising, or data brokerage.
