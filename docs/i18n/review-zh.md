# Chinese review — every user-visible string

Generated by `tool/i18n_review_zh.py` from the ARB files and `tool/i18n/native.json`; do not edit by hand. Terms: `docs/i18n/glossary.md`.

How to review: mark a row (or write the better wording next to it) and send it back; the fix goes into the ARB / native.json and this file is regenerated. zh-Hans is for Singapore, Malaysia and overseas readers (mainland-neutral); zh-Hant uses Taiwan wording (Hong Kong falls back to it). The translation-profile prompts (`… -> EN`) are sent to the AI model and stay in English on purpose.
